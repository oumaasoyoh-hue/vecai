# VECAI

**VECAI (Victoria Eagles Construct AI)** is a construction project management platform designed to help contractors, engineers, architects, quantity surveyors, suppliers, and project owners manage construction projects more efficiently.

The platform centralizes project information, tracks material usage, manages project documentation, and improves collaboration across construction teams. Future versions will leverage Artificial Intelligence to provide predictive insights, optimize material allocation, and improve project decision-making.

---

# Vision

To become Africa's leading intelligent construction management platform that enables construction professionals to deliver projects efficiently, transparently, and with minimal resource wastage.

---

# Mission

To digitize construction project management by providing an easy-to-use platform that improves collaboration, accountability, productivity, and decision-making through technology and AI.

---

# Problem Statement

Construction projects often rely on paper records, spreadsheets, WhatsApp groups, and phone calls to coordinate work. This results in:

* Material wastage
* Poor communication
* Cost overruns
* Project delays
* Limited accountability
* Inaccurate project reporting

VECAI aims to solve these challenges through a centralized digital platform.

---

# MVP Features

The first version of VECAI will focus on solving the core project management problems before introducing AI capabilities.

### Authentication

* User registration
* Login
* Role-based access

### Project Management

* Create projects
* Manage project details
* Track project status

### Team Management

* Invite project members
* Assign responsibilities

### Material Tracking

* Record material deliveries
* Track material usage
* Monitor inventory

### Document Management

* Upload project documents
* Store BOQs
* Store contracts and drawings

### Daily Site Reports

* Record daily work completed
* Track workforce productivity
* Monitor site progress
