# VECAI Development Roadmap

## Purpose

This roadmap outlines the planned development of VECAI (Victoria Eagles Construct AI) from concept to a production-ready MVP.

The roadmap is designed around three guiding principles:

* Build the smallest useful product first.
* Validate assumptions with real users.
* Improve through continuous iteration.

As a solo-founder project, development focuses on delivering value quickly while maintaining a high-quality codebase.

---

# Project Vision

Build a construction management platform that enables contractors, engineers, architects, suppliers, and clients to manage construction projects from a single platform.

Artificial Intelligence will be introduced after the platform has collected sufficient project data.

---

* PostgreSQL database

# MVP Scope

The MVP includes only the features required to solve the core construction management problem.

Included:

* Authentication
* User management
* Project management
* Team management
* Material tracking
* BOQ management
* Daily reports
* Document management

Excluded:

* AI recommendations
* Payments
* Mobile application
* Chat
* Advanced analytics
* Equipment tracking

# Risks

| Risk                       | Mitigation                                                            |
| -------------------------- | --------------------------------------------------------------------- |
| Learning Go while building | Build one feature at a time and follow idiomatic Go.                  |
| Solo development           | Keep the architecture simple and avoid unnecessary complexity.        |
| Scope creep                | Focus on the defined MVP and defer non-essential features.            |
| Limited budget             | Use open-source tools and free development resources where possible.  |
| Limited user feedback      | Engage contractors and construction professionals early for feedback. |

---

# Success Metrics

The roadmap will be considered successful if the following objectives are achieved:

* MVP released within 12 months.
* At least one real construction project managed using VECAI.
* Stable backend with documented APIs.
* Positive feedback from early users.
* Clear roadmap for AI-powered features.
